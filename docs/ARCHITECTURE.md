# Song_Guard 설계 및 운영 범위

## 목적
개인·법인 채권자의 근저당 및 공유지분 자산을 관리하고, 직접 임의경매·타인 신청 경매의 배당·직접 입찰·공유자 우선매수 검토와 취득 후 관리를 연결한다.

## 구현된 경계
- Python 표준 라이브러리 서버, SQLite 영속 저장, 계정별 자료 분리.
- 채권·담보/공유지분·사건·기한업무·변수의 등록/수정/조회와 연결.
- 비용→이자→원금 충당의 단일 연이율/365일 단리 계산. 실제 약정의 충당 방식, 이율변경, 지연손해금 중첩, 법정 최고이율의 역사적 적용은 자동 판정하지 않는다.
- 하나의 물건에 대한 선순위 금액·집행비용·담보한도 입력 기반 배당 시나리오. 공동담보 및 경합채권의 법률상 순위 배당은 전문가가 산정해 입력한다.
- 매각/배당/청구/특별지급 기일 입력 시 준비업무 자동 생성·미완료 업무 기일 변경 반영. 등록 날짜를 감시하며 외부 사건 변경을 자동 수집하지 않는다.
- 변수 18종 및 미분류 상황의 대응업무 생성. 법정 불복기간을 임의로 추정하지 않고 확인된 날짜를 입력한다.
- 공유자 우선매수 후보 판별. 소유권, 담보 목적 지분이전, 담보가등기를 구분하며 법적 효력을 자동 확정하지 않는다.
- 증빙 업로드/다운로드, 전체 ZIP 내보내기, 내부 검토자료 생성, 감사기록.
- 실제 증빙 ID 없이는 업무 완료 및 사건의 전액회수/직접취득 상태 저장 불가. 증빙의 진위와 충분성은 사용자가 확인한다.

## 미연동 기능
법원 전자소송 접수·전자서명·송달 수신, 인터넷등기소 발급, 은행 입금 확인, 외부 문자/메일 발송, OCR 및 AI 원문 판단은 구현된 외부 연동이 없다. 화면에 미연동 상태를 표시한다. 관련 기관의 공식 수단, 권한, 인증, 계약과 실제 검증을 확보한 뒤 별도 커넥터로 구현해야 한다. 현재 버전을 무인 법률대리/추심 서비스로 표시하지 않는다.

## 권리 관계
채권과 자산을 독립 저장하고 사건이 둘을 참조한다. 한 채권의 여러 사건 회수는 중복 계산하지 않도록 원장의 실제 변제로 반영해야 한다. 지분 이전은 대물변제인지 담보인지 계약을 검토한다. 지분의 명목 평가액을 회수액으로 자동 차감하지 않는다. 경매사건 회수액은 사건 기록이며 원장 자동 차감 기능이 아니다.

## 상태 및 예외
관리→집행준비→경매접수→매각진행→배당검토→수령대기→일부회수/전액회수 또는 직접취득을 화면에 표시한다. 외부에서 진행 중인 사건을 등록할 수 있어 순차 단계 강제는 하지 않는다. 불명확한 상황은 검토 업무로 등록한다. 변수별 원문·발생일·마감일·담당자를 기록한다. 법원 결정과 자료가 충돌하면 사용자가 검토 후 상태를 변경한다.

## 입찰 판단
제3자 낙찰 시 배당 추정과 직접취득 경제적 회수를 비교한다. 직접취득 경제적 회수=보수적 처분가−매수가−추가 비용+배당 추정. 이는 실현 수익 보장이 아니다. 필요한 현금과 경제적 손익은 구분한다. 우선매수는 최고가와 동일 가격 수용이 필요하고 단순 할인 매수가 아니다. 특별지급 미적용 전액 납부와 적용 시 차액 납부를 모두 표시한다. 보증금은 총현금에 중복 가산하지 않는다.

## 보안
PBKDF2-SHA256(600,000회) 비밀번호, 서버 세션(8시간), HttpOnly/SameSite=Strict/Secure 쿠키, CSRF 토큰, Origin 확인, 계정별 서버 접근 통제, 갱신 버전 충돌 방지, 로그인 15분/20회 제한, 12MB 업로드 한도, 첨부 강제 다운로드, CSP, 프레임 차단. 가입 기본 비활성화. 단일 인스턴스 전제이며 SQLite 영속 볼륨이 필수다. 백업을 암호화 보관하고 호스트/볼륨 암호화·TLS·접근권한·보존기간을 운영자가 설정해야 한다. 감사기록은 DB 관리자에 대한 변조방지 보장이 없다.

## 알려진 제한
배당/입찰 가격 예측, 자동 제출, 자동 입찰, 알려지지 않은 모든 법률 변수의 완전한 자동 판단은 제공하지 않는다. 모든 변수의 완벽한 보장을 주장하지 않는다. 공유물분할·일괄매각 우선매수, 담보 목적 소유권의 청산, 조세·임차권·공동담보는 개별 원문과 법률 검토가 필요하다. 국내 사건에 맞춰 설계되며 국제 사건은 별도 검토한다.
